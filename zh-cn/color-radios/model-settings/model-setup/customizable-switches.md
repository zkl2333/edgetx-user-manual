# 可自定义开关

传统的6位开关/控制要么是一组6个开关协同工作（一次只能激活一个），要么是具有六个物理位置（定位）的单个旋转开关。一些新一代遥控器提供了"可自定义开关"功能，允许您定义开关的类型、分组和启动状态。从物理上看，它们看起来像您在旧手持设备设计中看到的普通6位开关，但它们_**要**_灵活得多。

{% hint style="info" %}
如果您确实需要可自定义开关的行为与传统6POS开关**完全相同**，则需要将六个可自定义开关配置为单个组，将该组设置为"始终开启"，并将组的启动设置为第一个开关。然后，您将能够使用例如 GR1 来代替 6POS。
{% endhint %}

<figure><img src="/.gitbook/assets/colorlcd_model_customisable_switches.png" alt=""><figcaption><p>一个支持的手持设备上的可自定义开关选项示例。</p></figcaption></figure>

**名称：** 您希望为每个可自定义开关指定的任何三个字母的名称。

**类型：** 可以设置为以下任一选项

* **None（无）**：基本上是禁用
* **Toggle（切换）**：仅在按下时可自定义开关才"激活"
* **2POS（2位）**：按下开关将交替其状态。即 关 按 开 按 关 ....
* **3POS（3位）**：按下开关将在 3 个状态之间循环。
* **Global（全局）**：开关的类型/行为取自遥控器设置中的可自定义开关配置，而不是按模型单独配置。

**组：** 在这里您可以选择如何对各个开关进行分组。您可以选择将它们放在单个组中（默认为组1），然后可以像传统的6POS开关一样使用它们。或者，您可以将它们定义为单独的组（例如，如上所示的SW1-SW3和SW4-SW5），甚至可以让某些开关完全不在组中（例如，如上所示的SW6）。

您可以通过 GR# 选项将各个组用作输入或混控的源，其中 # 表示组的编号（例如 GR1、GR2）。

当开关被分组时，组中一次只能有一个开关处于激活状态。此外，您可以指定组中必须始终打开一个开关 **"Always on（始终开启）"**。

**启动：** 在这里您可以指定不在组中的2POS可自定义开关或一组可自定义开关的启动状态。您可以将其指定为"Last（最后）"（记住发射机关闭或模型更改时的最后状态）或处于上（释放）或下（按下）状态。

**OFF / ON 颜色（在兼容的手持设备上）：** 某些手持设备支持配置可自定义开关的颜色。如果是这样，将为每个可自定义开关显示 OFF 和 ON 颜色选择器（如下所示），您将能够为每种状态选择您喜欢的颜色。黑色表示可自定义开关未点亮时的状态。

<figure><img src="/.gitbook/assets/colorlcd_model_customisable_switches_rgb.png" alt=""><figcaption><p>同时支持配置 LED 颜色的手持设备上的可自定义开关选项</p></figcaption></figure>

**Lua Override（在兼容的手持设备上）：** 在 OFF 和 ON 颜色选择器旁边，各显示一个开关，允许正在运行的 Lua 脚本在运行时覆盖该状态下所配置的 LED 颜色。
