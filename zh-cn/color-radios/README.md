# 彩屏遥控器用户手册

<figure><img src="/.gitbook/assets/colorradios.png" alt=""><figcaption><p>EdgeTX 支持的彩屏遥控器</p></figcaption></figure>

EdgeTX 支持以下彩屏遥控器（以及许多其他型号）：

* FlySky NV14 / EL18
* FlySky PL18 / PL18 EV
* FrSky X10 / X10S / X10 Express / X10S Express
* FrSky X12S / X12S-IRSM
* Jumper T15
* Jumper T16 / T18
* RadioMaster TX16S
* RadioMaster TX15
