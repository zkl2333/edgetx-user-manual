# 遥控器设置

<figure><img src="/.gitbook/assets/screenshot_tx16s_25-12-15_15-32-00.png" alt=""><figcaption><p>遥控器设置部分的顶部</p></figcaption></figure>

遥控器 **设置** 部分包含配置遥控器的所有选项。在页面顶部，您会看到一些图标，选择这些图标将带您进入不同的遥控器设置页面。遥控器设置的默认屏幕是 [工具](apps.md) 屏幕。

遥控器设置屏幕顶部的图标包括（从左到右的顺序）：

* [应用](apps.md)
* [存储](storage.md)
* [遥控器设置](radio-settings/)
* [主题](themes.md)
* [全局功能](global-functions.md)
* [教练](trainer.md)
* [硬件](hardware.md)
* [关于](about.md)
