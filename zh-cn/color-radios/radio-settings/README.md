# 遥控器设置

遥控器 **设置** 部分包含配置遥控器的所有选项。在页面顶部，您会看到一些图标，选择这些图标将带您进入不同的遥控器设置页面。遥控器设置的默认屏幕是 [工具](tools.md) 屏幕。

遥控器设置屏幕顶部的图标包括（从左到右的顺序）：

* [工具](tools.md)
* [SD 卡](sd-card.md)
* [遥控器设置](radio-setup/)
* [主题](themes.md)
* [全局功能](global-functions.md)
* [教练](../model-settings/model-setup/trainer.md)
* [硬件](hardware.md)
* [版本](version.md)
