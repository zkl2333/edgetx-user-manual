# 直升机设置

在模型设置中的**直升机设置**页面是一个可选页面，适用于自定义编译版本的EdgeTX。直升机设置页面通常用于集体俯仰混控（CCPM），用于接收机直接控制斜盘伺服的有平衡翼的直升机。大多数无平衡翼直升机不需要配置此页面。CCPM 混控器的输出为CYC1、CYC2和CYC3，需要在混控屏幕上分配到一个输出通道。

<figure><img src="/.gitbook/assets/bwheli.png" alt=""><figcaption><p>直升机设置屏幕</p></figcaption></figure>

直升机设置屏幕具有以下配置选项：

* **斜盘类型** - 您模型的斜盘类型。选项有 **---**（禁用直升机/CCPM 混控）、**120, 120x, 140, 和 90。**
* **斜盘环** - 仅在需要时设置斜盘环限制。**1** = 最大限制 -> **100** 或 **0** = 无限制。&#x20;
* **纵向循环源** - 选择源输入。
  * **权重** - 使用摇杆行程的百分比值。
* **横向循环源** - 选择源输入。
  * **权重** - 使用摇杆行程的百分比值。
* **集体俯仰源** - 选择源输入。&#x20;
  * **权重** - 使用摇杆行程的百分比值。
