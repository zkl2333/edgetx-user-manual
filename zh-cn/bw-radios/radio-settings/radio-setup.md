# 遥控器设置

<figure><img src="/.gitbook/assets/bw128_radio_setup_top.png" alt=""><figcaption><p>遥控器设置</p></figcaption></figure>

**遥控器设置**屏幕是配置遥控器基本设置的地方。它包含以下选项：

**日期** - 当前日期。此日期用于SD卡日志文件。

**时间** - 当前时间。此时间用于SD卡日志文件。

**One log per day（每天一个日志）** - 启用后，对于某个模型每天只创建一个 SD 卡日志文件，而不是每次开始记录日志时都创建一个新文件。

**Lock keys（按键锁定，部分遥控器）** - 启用后，同时按住选项标签中注明的两个按键（例如 "Lock keys (SYS+MDL)"）即可锁定遥控器按键。具体按键组合因遥控器型号而异。仅在按键布局合适或硬件按键足够的遥控器上可用。

**电池范围** - 设置电池电压表的最大和最小电压。这应根据您使用的电池类型进行设置。



<figure><img src="/.gitbook/assets/bw128_radio_setup_sound.png" alt=""><figcaption><p>声音设置</p></figcaption></figure>

### **声音**

**模式** - 配置何时播放声音。

* **全部 -** 按下按钮时发出蜂鸣声，并在有警报或警告时播放声音。
* **无按键 -** 按下按钮或转动滚轮时无蜂鸣声，但在有警报或警告时播放声音。也播放由特殊功能触发的声音。
* **警报 -** 仅播放警报或警告声音。也播放由特殊功能触发的声音。
* **静音 -** 不播放蜂鸣声或声音。

**音量 -** 遥控器的主音量。

**蜂鸣音量** - 不言自明

**蜂鸣长度** - 不言自明

**蜂鸣音调** - 不言自明

**Wav音量 -** 警报和警告的音量以及通过**播放轨道**特殊功能播放的声音

**背景音量 -** 通过**背景音乐**特殊功能播放的背景.wav文件（音乐）的音量

**启动声音 -** 启用时（默认设置），在遥控器启动时播放 "Welcome to EdgeTX" 声音。相关文件位于 `/SOUNDS/??/SYSTEM/hello.wav`（其中 \`??\` 代表您的声音包的两个字母目录）。

<figure><img src="/.gitbook/assets/bwRadioSetup3 (1).png" alt=""><figcaption><p>变音器设置</p></figcaption></figure>

### **变音器（Variometer）**

**音量** - 变音器蜂鸣声的音量

**零音调** - 低音调频率

**最大音调** - 高音调频率

**重复零 -** 音调重复前的时间，以毫秒为单位

{% hint style="info" %}
注意：为了使变音器功能正常，必须通过**变音器**特殊或全局功能打开。有关如何配置的更多信息，请参见[特殊功能](../../color-radios/model-settings/special-functions.md)。
{% endhint %}

### 触觉

**模式** - 配置遥控器何时振动。

* **全部 -** 按下按钮时振动，以及在有警报或警告时振动。
* **无按键 -** 按下按钮或转动滚轮时无振动，但在有警报或警告时振动。
* **警报 -** 仅在警报或警告声音时振动。
* **静音 -** 不振动

**长度** - 振动的持续时间。

**强度** - 振动的强度

<figure><img src="/.gitbook/assets/bw128_alarms.png" alt=""><figcaption><p>警报设置</p></figcaption></figure>

### 警报

* **电池低** - 触发低电池警报的电压。
* **不活动** - 触发不活动警告的时间。
* **内存低** - 启用/禁用低内存警告。
* **声音关闭** - 如果声音模式设置为静音，则在发射机打开时显示"警报已禁用"视觉警告。
* **RSSI关机** - 在尝试关机时检查接收器是否仍连接到遥控器。如果检测到，则发出音频和视觉警报。
* **教练关机** - 在尝试关机时检查是否仍有教练信号激活。如果检测到，则发出音频和视觉警报。

<figure><img src="/.gitbook/assets/bw128_backlight.png" alt=""><figcaption><p>背光设置</p></figcaption></figure>

### 背光

**模式**

* **关闭** – 始终关闭。
* **按键** – 按下按钮时打开。
* **控制** – 使用摇杆、开关和旋钮时打开。
* **两者** – 使用按钮、摇杆、开关和旋钮时打开。
* **开启** – 始终开启。

**持续时间** - 背光开启的秒数。最小值为5秒。最大值为600秒。

**亮度** - 调整屏幕背光亮度级别。

**对比度** - 对于LCD显示器，调整屏幕对比度设置。对于OLED显示器，调整OLED亮度级别。

**警报** - 当有警报或警告时，背光会打开。

<figure><img src="/.gitbook/assets/bw128_radio_setup_misc1.png" alt=""><figcaption><p>杂项设置</p></figcaption></figure>

### 杂项设置

**启动画面** - 显示启动画面的持续时间。选项有 **`---`**（无启动画面）、**2s, 3s, 4s, 6s, 8s, 10s, 15s**

**开机延迟** - 按下电源按钮与遥控器开机之间的延迟。选项有：**0s, 0.5s, 1s, 2s, 3s**

**关机延迟** - 按下电源按钮与遥控器关机之间的延迟。选项有：**0s, 0.5s, 1s, 2s, 3s, 4s**。_建议至少设置1秒的延迟，以防止因意外按下按钮而关闭遥控器。_

**自动关机** - 如果启用（默认未启用），如果手持设备处于非活动状态，且没有教练或遥测链接激活，它将在配置的持续时间后自动关闭。您可以选择从 **0**（禁用）到 **255**（分钟）。

**开/关机触觉** - 如果启用（默认启用），在开机和关机延迟结束后，将有触觉振动以指示遥控器正在开机或关机。

**Model quick select（模型快速选择）** - 如果启用（默认禁用），在[模型选择](../model-select/#模型选择)屏幕中选择模型后，会在模型加载完成后返回主视图，而不是停留在选择菜单。

**所有者ID**（选定发射机）- 仅用于具有ISRM内部RF模块的用户的自定义注册ID，或在支持FrSky ACCESS外部模块的发射机上。如果未手动配置，将使用随机值。

### IMU（部分遥控器）

仅在内置陀螺仪、可用于基于倾斜/运动的虚拟摇杆控制的遥控器（例如 X-Lite S）上可用。

**IMU Max** - 对应摇杆满行程的倾斜角度（单位：度）。

**IMU Offset** - 校准偏移量（单位：度），用于修正遥控器未完全水平握持时的偏差。

<figure><img src="/.gitbook/assets/bw128_radio_setup_gps.png" alt=""><figcaption><p>GPS设置</p></figcaption></figure>

### **GPS**

**时区** - 遥控器使用的时间与UTC的偏移量。可以以15分钟为增量进行配置。

**调整RTC** - 调整发射机的实时时钟以匹配GPS确定的时间。

**GPS坐标** - 将显示的GPS坐标格式。

<figure><img src="/.gitbook/assets/bw128_radio_setup_misc2.png" alt=""><figcaption></figcaption></figure>

**杂项设置**

**国家代码** - 由某些RF模块使用，以确保遵守当地的RF法规要求。选项有**美国、日本、欧洲。**

**语音语言** - 语音包的语言。此设置和SD卡上的语音包文件夹必须匹配，以便播放声音。

**单位** - 测量单位。选项有**公制**或**英制**。

**PPM单位** - 显示PPM值的精确度级别。选项有 **0.-**、**0.0** 或 **us**（微秒）。

**播放延迟**（开关中间位置）- 开关必须处于中间位置的最短时间（以毫秒为单位），以便特殊功能被激活。这用于防止在从低位置切换到高位置时，三位置开关的中间位置被激活。

<figure><img src="/.gitbook/assets/bwRadioSetup9.png" alt=""><figcaption></figcaption></figure>

**USB模式** - 设置当USB数据端口插入USB电缆并打开遥控器时的默认操作。选项有：**询问**（连接时询问，默认）、**操纵杆**（Joystick）、**SD卡**（Storage）和**串行**（Serial）。

**默认通道顺序** - 新模型和教练屏幕的默认通道顺序。字母代表：**A** = 副翼，**E** = 升降舵，**T** = 油门，**R** = 方向舵。更改此设置不会影响现有模型。在地面遥控器上，字母代表**S**=转向，**T**=油门。

**旋转编码器模式**（旋转编码器模式）（选定遥控器）- 设置滚轮的旋转方向。选项有：

* **正常** (默认)
* **反转** = 反转滚轮的方向
* **垂直反转，水平正常** = 垂直反转，水平正常
* **垂直反转，水平备用** = 垂直反转，水平备用（反转）
* **垂直正常，编辑反转** = 垂直正常，编辑反转（编辑文本时反转）

**模式** - 发射机将使用的摇杆模式。由左摇杆执行的动作定义。选项有：

### 启用的功能

遥控器设置的**启用的功能**部分允许您配置EdgeTX中遥控器设置和模型设置区域中可见的_**全局**_ _**设置**_。活动模型的配置设置将显示在复选框的右侧。模型配置将覆盖全局配置（这将通过任何模型级别覆盖旁边显示的"关闭"和"开启"来指示）。

{% hint style="info" %}
_**注意：**_ 关闭一个选项卡只会隐藏该选项卡，并不会更改该选项卡中已配置的项目。

**例外：** 关闭全局/特殊功能选项卡将禁用为该模型配置的全局/特殊功能。
{% endhint %}
